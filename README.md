🍽️ Responsive Animated Restaurant Website

A modern, responsive, and animated restaurant website built with HTML5, CSS3, and JavaScript.

This project is designed for restaurants, cafés, food businesses, and personal frontend portfolios. It features a clean modern interface, smooth animations, responsive layouts, interactive navigation, menu filtering, and an attractive food-focused design.

🚀 Getting Started
1. Clone the repository
git clone https://github.com/yourusername/responsive-animated-restaurant.git
2. Open the project
cd responsive-animated-restaurant
3. Run the website

Open:

index.html

in your browser.
